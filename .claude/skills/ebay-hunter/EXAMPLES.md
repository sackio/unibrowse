# Cluster Hunter - Examples

This document shows example outputs and usage patterns for the Cluster Hunter skill.

---

## Usage

### Basic Invocation

```bash
/cluster-hunter
```

Executes with default settings:
- Maximum cost per node: $130
- Instant buy threshold: $110
- Searches for 10th Gen+ Intel or Ryzen 4000/5000+
- Falls back to 8th/9th Gen Intel (<$80/node) if zero results

### With Custom Parameters

```bash
/cluster-hunter max-price=150
```

Accepts deals up to $150/node instead of $130.

```bash
/cluster-hunter instant-buy=100
```

Marks deals under $100/node as instant buy instead of $110.

```bash
/cluster-hunter max-price=140 instant-buy=105
```

Combines both parameters.

**Title**: "Lot of 5 Dell OptiPlex 3080 Micro i5-10500T 8GB 256GB SSD with AC Adapters"

**Why Accepted**:
- ✅ Bulk lot detected: "Lot of 5"
- ✅ Quantity extracted: 5

## Cost Calculation Examples

### Example 1: Power Adapter Included

**Listing**:
- Item Price: $450
- Shipping: $45
- Quantity: 5
- Title mentions: "with AC adapters"

**Calculation**:
```
powerAdapterCost = 0 (adapters included)
totalCost = $450 + $45 + $0 = $495
costPerNode = $495 / 5 = $99.00
```

---

### Example 2: No Power Adapter

**Listing**:
- Item Price: $900
- Shipping: $30
- Quantity: 10
- Title does NOT mention power adapters

**Calculation**:
```
powerAdapterCost = $12 × 10 = $120 (add $12 per node)
totalCost = $900 + $30 + $120 = $1,050
costPerNode = $1,050 / 10 = $105.00
```

**Note**: $12 per node is the approximate cost of a compatible 65W AC adapter for micro desktops.

---

### Example 3: Free Shipping

**Listing**:
- Item Price: $800
- Shipping: $0 (free)
- Quantity: 8
- Power adapters: Not mentioned

**Calculation**:
```
powerAdapterCost = $12 × 8 = $96
totalCost = $800 + $0 + $96 = $896
costPerNode = $896 / 8 = $112.00
```

**Classification**: ✅ Good Deal ($112 is between $110-$130)

## Ranking Examples

Two deals with similar pricing - which ranks higher?

### Deal A: Lower Price, Lower Seller Rating

- Cost per node: $100
- Seller rating: 95.0% (200 reviews)
- Listing type: Auction
- Shipping: Paid ($20)

**Score Calculation**:
```
priceScore = ((130 - 100) / 130) × 0.4 = 0.092
sellerScore = (95.0 / 100) × 0.3 = 0.285
typeScore = 0.05 (auction)
shippingScore = 0.05 (paid shipping)
TOTAL = 0.477
```

### Deal B: Higher Price, Higher Seller Rating

- Cost per node: $108
- Seller rating: 99.5% (5000 reviews)
- Listing type: Buy It Now
- Shipping: Free

**Score Calculation**:
```
priceScore = ((130 - 108) / 130) × 0.4 = 0.068
sellerScore = (99.5 / 100) × 0.3 = 0.299
typeScore = 0.15 (buy it now)
shippingScore = 0.15 (free shipping)
TOTAL = 0.667
```

**Winner**: Deal B ranks higher (0.667 > 0.477) despite higher price due to better seller rating, Buy It Now convenience, and free shipping.

## Performance Metrics

**Expected Execution Time**:
- Per search query: 5-10 seconds (search + filter + extract)
- 8 queries with 2-second delays: ~1-2 minutes
- Fallback (if needed): +1-2 minutes
- Email generation: 2-5 seconds
- **Total**: 3-5 minutes typical, 10-15 minutes with fallback

**Token Usage**:
- Per query extraction: ~2,000-5,000 tokens (depends on result count)
- 8 queries: ~20,000-40,000 tokens
- Email generation: ~5,000-10,000 tokens
- **Total**: ~30,000-60,000 tokens per run

**Network Requests**:
- Per query: 4 macro executions (search, filter, sort, extract)
- 8 queries: 32 macro executions
- Fallback: +32 macro executions
- **Total**: 32-64 macro executions per run
